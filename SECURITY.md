# Security Policy

## Supported versions

Only the latest AnymousDEX release is supported with security updates.

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's
[Security Advisories](https://github.com/anymousdark/anymousdex/security/advisories/new)
for this repository. Do not open a public issue for an unfixed vulnerability.

Include the affected version, a description of the issue and, when possible,
steps to reproduce it. You should receive a response within a few days.

## Scope

AnymousDEX runs a local terminal server on `127.0.0.1` and loads local files
through Electron. Reports about remote code execution, unsafe file handling,
privilege escalation or data exposure are especially welcome.
